# Optional generated ClockEra diagnostic value

Header `logging/DiagnosticClockEraArguments.hpp` activates the optional ClockEra encoding profile (version 0.1.0). Imports Serialisation's own `ClockEraAdapters.hpp` and certifies only `Clock::ClockEra` against a generated `clock-era` diagnostic parameter; raw `uint64_t` is rejected. Canonical CBOR unsigned integer / JSON decimal use the existing Serialisation owner codecs. Zero stays invalid; nonzero is **not** temporal or election provenance. The default Logging adapter remains Clock-independent and the separate semantic LogRecord root identity has been permanently issued by EDP-System, but this diagnostic argument adapter neither issues that identifier nor qualifies synchronized clock evidence.
