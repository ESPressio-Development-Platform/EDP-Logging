# logging/AdmissionWakeCoordinator.hpp — composed G1 wake fanout

**Component-level** application-composed, allocation-free fixed-slot producer notification mechanism. No direct platform concrete dependency or default Logging umbrella import. See [full owner contract](../docs/ADMISSION-WAKE-COORDINATOR.MD).

## Public types

- `AdmissionWakePublicationResult` (strong `uint8_t`): `NotAttempted=0`, `Published=1`, `ProviderFailure=2`, returned by `PublishCapacityAvailable()` after all configured wake targets are attempted.
- `CoordinatedAdmissionResult` (value Type): `Admission` of `AdmissionWaitResult` and `Notification` of `AdmissionWakePublicationResult`; distinguishes ownership from wake failure.
- `CoordinatedReleaseResult` (strong `uint8_t`): `ReleasedAndNotified=0`, `ReleasedNotificationFailed=1`, `AlreadyEmpty=2`, `MemoryProviderFailure=3`.
- `AdmissionWakeCoordinator<TProducerCount,TWaitWakeProvider>`: borrows one long-lived Bootstrap-composed EDP-Threading BoundedWaitWake owner. No dynamic registration, no coordinator heap allocation, no copy/move. Compile-time asserts `TProducerCount>0` and sufficient provider capacity.

## Methods and internal layout

- `PublishCapacityAvailable() noexcept`: O(`TProducerCount`) wake fanout, fail status preserved even if later slots succeed.
- `ReleaseAndNotify(lease) noexcept`: Memory owner `ObjectPoolLease::Release()` followed by wake fanout **only if released**, preserving native provider-failure and release notification-failure separately.
- `AcquireUntil<TMaximumWakeRetries>(slot, pool, lease, deadline, arguments...) noexcept`: checks slot range, constructs a stack-local `SlotWaitPoint` adapter without *registering* a pointer or escaping lifetime, reuses `AcquirePoolUntil` canonical Clock deadline and Memory **NoWait** policy, then wakes all slots on successful claim. Slot adapter maps Threading `BoundedWaitWakeResult` to the exact `BoundedWaitResult` typed in `BoundedAdmission.hpp`; other failure becomes `ProviderFailure`.
- Internal members: one borrowed pointer `_waitWake`. The nested adapter retains only the owner pointer and one size_t slot; no shared mutable application state is maintained.

**Important invariant:** producer slot identity is exclusive and its Threading signal must latch Notify-before-Wait. Every capacity release (including RAII destruction/other consumers) must be paired with a wake: the helper cannot intercept uncoordinated `lease.Release()` or RAII cleanup. **Historical early implementation boundary:** this *wake fan-out helper* alone has never owned FIFO entitlement, cancellation or whole-worker deadline. The subsequently implemented [TransactionalRecordQueue](Reference-logging-TransactionalRecordQueue), [Admission Lifecycle](Reference-logging-AdmissionLifecycleCoordinator), [Tracked Admission](Reference-logging-TrackedAdmissionCoordinator) and [Dedicated Coordinator](Reference-logging-DedicatedCoordinator) now implement and separately test the relevant bounded source/worker contracts. Their existence does **not** certify every native provider's timeout fidelity or arbitrary blocking sink latency.

## 12 November 2026 — source-level status, slot and ownership completion

**Current source:** [`src/logging/AdmissionWakeCoordinator.hpp`](../src/logging/AdmissionWakeCoordinator.hpp). The PUBLIC enum `AdmissionWakePublicationResult : uint8_t` has **NotAttempted (0)** (no wake requested on this path), **Published (1)** (all configured target wakes accepted), **ProviderFailure (2)** (one or more wakes failed even though later targets were still tried). The value struct `CoordinatedAdmissionResult` holds independent **Admission: AdmissionWaitResult** (actual NoWait/deadline/late-grant lease outcome) and **Notification: AdmissionWakePublicationResult** (advisory fan-out health). The PUBLIC `CoordinatedReleaseResult` has **ReleasedAndNotified (0)**, **ReleasedNotificationFailed (1)** (release proven, wake failed), **AlreadyEmpty (2)**, and **MemoryProviderFailure (3)** (native release not proven; must not claim capacity).

**`AdmissionWakeCoordinator<TProducerCount,TWaitWakeProvider>`** requires positive fixed slot count, existing EDP-Threading `BoundedWaitWake` owner capacity at least `TProducerCount`, and a caller-assigned **exclusive producer slot** for every live producer. The private **`_waitWake : TWaitWakeProvider*`** is the only retained state; the explicit constructor borrows it and never owns signal, waiter list, task, clock or heap. Copy/move are deleted because active producers rely on the provider's stable identity. **`PublishCapacityAvailable()`** attempts bounded wake fan-out to *every* configured slot even if one fails. **`ReleaseAndNotify<TLease>(lease)`** invokes the existing EDP-Memory native release and publishes capacity only on a proven successful release; AlreadyEmpty and failure are not upgraded. **`AcquireUntil<TMaximumWakeRetries,TObjectPool,TLease,TArguments...>(slot,pool,lease,deadline,args...)`** validates slot before mutation, creates a temporary nonescaping `ThreadingWaitSlot` adapter, reuses the one canonical absolute EDP-Clock deadline and the separately qualified Memory **NoWait** path, and fan-out notifies on **Admitted** or **GrantedAfterDeadline**, preserving the caller's actual live lease on late grants. No allocation or hidden retry beyond finite template wake count is introduced; companion higher-level tracked/lifecycle owner supplies cancellation and bounded shutdown drain.
