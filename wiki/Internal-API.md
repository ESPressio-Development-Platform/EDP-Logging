# Internal reusable implementation contracts

Generated LogRecord wire projections, typed positional rehydration, EDLS retirement proofs, dedicated Threading coordinator, and reusable ByteOperations provider selection are internal cross-library implementation seams, not independently composable SDK providers.

## Boundaries

Generated message signatures and original field coordinates must agree with Localisation/System; private source kinds are not wire discriminators. Internal details remain available in the [Reference Index](Reference-Index).

See [Reference Index](Reference-Index) for source-by-source declarations and [Tooling Reference](Tooling-Reference) for maintained decoder and evidence tools.
