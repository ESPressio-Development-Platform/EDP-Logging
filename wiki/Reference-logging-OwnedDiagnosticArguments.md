# Source reference — bounded owned diagnostic source arguments

**Classification:** PUBLIC OPTIONAL source-ownership API, with INTERNAL argument descriptor/encoding vocabulary and PRIVATE bounded arena. **Exact reviewed source:** [src/logging/OwnedDiagnosticArguments.hpp](../src/logging/OwnedDiagnosticArguments.hpp). EDP-Logging 0.1.0. This module uses **EDP-Memory ByteOperations** via the existing narrow **EDP-Platform-Portable ByteOperations concrete**, and the authoritative **EDP-Serialisation UTF-8 validator**; EDP-System's issued strong Device, Incarnation, Type and Field identities remain under their existing owners. EDP-Clock `ClockEra` is forward declared and only used by an explicitly selected `AddClockEra` overload; there is no always-on Clock/mesh dependency. **In-memory source byte kinds are NOT new EDLG/CBOR wire tags**.

## Source `OwnedArgumentKind : uint8_t` — every representation

This internal source-side discriminator uses exact, fixed numeric values to recover the correct governed Type **from owned record storage**:

- **Boolean (0)** — an exact bool stored in native private bytes; **Signed8 (1)**, **Signed16 (2)**, **Signed32 (3)**, **Signed64 (4)** — respective fixed signed scalar widths;
- **Unsigned8 (5)**, **Unsigned16 (6)**, **Unsigned32 (7)**, **Unsigned64 (8)** — corresponding fixed unsigned widths;
- **Float32 (9)** and **Float64 (10)** — exact IEEE-compatible C++ float/double native source representation, retaining bits until canonical EDP-Serialisation encodes them;
- **Utf8 (11)** — strictly validated canonical UTF-8 text, including embedded-NUL rejection, and copied as exact bytes;
- **Bytes (12)** — arbitrary bounded binary bytes, which may contain NUL and need their own generated argument schema;
- **TypeIdentifier (13)** — an already valid EDP-System issued 8-byte Type identity, never reconstructed from a guess;
- **DeviceIdentifier (14)** — an already valid EDP-System issued 16-byte Device identity;
- **FieldIdentifier (15)** — one-byte strong governed System Field identity, where numeric zero is valid **within its Type**, not a wire tag;
- **RuntimeIncarnationId (16)** — the strong 32-bit System incarnation value, including an observable zero sentinel (which still cannot qualify an emitting LogRecord root);
- **ClockEra (17)** — the exact owner-issued EDP-Clock strong era value, including zero/unavailable, selected only through the optional Clock-qualified template overload.

These numbers serve private in-memory classification and must never be used to bypass the generated message schema, import an untrusted native byte order into public wire, or duplicate the EDP-Serialisation canonical encoder.

## Typed result and descriptor Types

`OwnedArgumentResult : uint8_t`: **Added (0)** means one *complete* argument descriptor and its bytes committed in the fixed arena; **CountExceeded (1)** means no descriptor slot remains; **BytesExceeded (2)** means no room for the complete argument representation; **InvalidUtf8 (3)** means the authoritative validator rejected malformed, noncanonical or NUL-containing text; **UnsupportedType (4)** means a strong System identity or scalar Type cannot be qualified under its existing owner (a non-exact scalar template instantiation can instead be rejected at compile time). Every refusal leaves prior descriptors and data logically unchanged; the operation never partially advances its authoritative count.

`OwnedArgumentAccessResult : uint8_t`: **Available (0)** means the indexed already-stored descriptor/span was returned, **OutOfRange (1)** means the index is outside the current committed count and the caller's output is preserved unchanged. This is distinct from a byte-capacity or schema failure.

`OwnedArgumentDescriptor` is a small value Type with **Kind : OwnedArgumentKind** (source-side semantic type, default Bytes), **Offset : uint16_t** (beginning of the value in the source record's own fixed byte arena, default zero), and **Size : uint16_t** (length of its fully copied representation, default zero). It is a view *descriptor* into the original record's stable storage, not a heap pointer or permanently serialized field. No external caller's source span survives a successful capture.

## `OwnedDiagnosticArguments<TMaximumArguments=8,TMaximumBytes=128,TByteOperationsProvider=Portable::Memory::ByteOperationsProvider>`

**Template parameters:** `TMaximumArguments` is the positive compile-time **1–64** argument descriptor capacity; `TMaximumBytes` is the positive compile-time **1–4096** aggregate byte arena capacity, not an allocation request at runtime; `TByteOperationsProvider` is an existing stateless, nothrow-default-constructible EDP-Memory ByteOperations provider and defaults to the qualifying Portable concrete. The compile-time EDP-Memory `ByteOperationsProviderTraits` contract verifies support. No alternate ByteOperations implementation, allocator or hidden ownership container is introduced; the exact arena sizes become part of the containing LogRecord's fixed-size memory footprint.

**Every private retained member:** **`_items : array<OwnedArgumentDescriptor,TMaximumArguments>`** owns the finite indexed descriptor table; **`_data : array<byte,TMaximumBytes>`** owns every captured byte (never points into the original caller); **`_count : size_t`** is the authoritative committed descriptor count, initially zero and never greater than TMaximumArguments; **`_used : size_t`** is the authoritative committed byte count, initially zero and never greater than TMaximumBytes. Both counts are incremented **only after** preflight and complete synchronous copy, so an attempted append that fails cannot advertise partially copied argument ownership. No heap, std::vector, retained caller buffer, background task or shared mutable state exists.

**Private `Store(kind,span<const byte> data) noexcept`** checks descriptor and byte capacity before any mutation, performs a bounded `TByteOperationsProvider{}.CopyBytes` only when input is nonempty, then writes the exact descriptor at `_items[_count]` and advances `_used`/`_count`. The borrowed input span need only remain valid for the call; all committed bytes are record-owned. There is no independent runtime mutex or fallible allocator. The method returns Added/CountExceeded/BytesExceeded and guarantees prior committed arguments remain unaltered on refusal.

## Every public accessor, capture method and constraint

The constexpr default constructor creates zero-used fixed internal storage without an allocation, time read or filesystem operation. **`Count() const`** returns committed argument count, **`BytesUsed() const`** returns actual copied byte occupancy, **`ByteCapacity()`** and **`ArgumentCapacity()`** return the compile-time capacities, not current availability.

**`GetDescriptor(index,OwnedArgumentDescriptor& output) const`** checks `index < _count`, then copies descriptor into output; out-of-range leaves output unchanged. **`GetArgumentBytes(index,span<const byte>& output) const`** borrows an exact view into `_data` using the stored descriptor offset/size, only when index exists; out-of-range leaves the caller's existing output unchanged. A returned span is valid **only for the lifetime of that original source-argument owner** and must not be stored beyond its native record lease or treated as a persistent/wire reference. Neither accessor transfers ownership or mutates counts.

**`AddScalar<TValue>(value)`** accepts **only** exact-width bool, int8/16/32/64, uint8/16/32/64, float and double. A different C++ scalar (such as target-specific long double or unapproved strong Type) fails a static assertion instead of guessing its width. It `std::bit_cast`s the value to native source-only bytes, chooses exactly the corresponding OwnedArgumentKind and invokes Store; only the later canonical encoder may assign portable CBOR/JSON semantics. **Template parameter TValue** is the exact original scalar Type, including its storage width.

**`AddUtf8(string_view text)`** borrows text only during this call; validates with the **existing EDP-Serialisation** strict UTF-8 validator (rejects embedded NUL) and then copies the exact byte sequence using Store(Utf8). If the caller needs NUL-bearing data, **`AddBytes(span<const byte>)`** copies it as binary Bytes, subject to the corresponding generated schema, not as arbitrary invalid Unicode.

**`AddTypeIdentifier(const System::TypeIdentifier&)`** demands owner-issued valid Type identity, copies its canonical 8 bytes, otherwise returns UnsupportedType. **`AddFieldIdentifier(System::FieldIdentifier)`** copies its one-byte value without rejecting zero (zero is legal within a Type). **`AddDeviceIdentifier(const System::Identity::DeviceIdentifier&)`** demands a valid strong 16-byte identity, otherwise UnsupportedType. **`AddRuntimeIncarnationId(const System::Identity::RuntimeIncarnationId&)`** copies the exact 32-bit value; allowing an observed zero does **not** make that zero valid as the source of a new emitted LogRecord. **`AddClockEra<TEra>(const TEra&)`** is an optional adapter whose `TEra` must be exactly the existing `ESPressio::Clock::ClockEra` strong Type; it captures its 64-bit value but does not bind a Clock publisher, assume synchronization, correlate nodes or create a new era. The Type and device methods borrow a byte view of the owner’s fixed array until Store finishes its single EDP-Memory copy. All these methods are synchronous and return the common typed finite-capacity result without retaining external references.

## Serialization, concurrency and failure boundaries

The private arena may retain native byte order, layout and IEEE bit representation for **local transient ownership only**. `OwnedDiagnosticPositionalReencoding` and EDP-Serialisation's canonical TypedEnvelope encoder transform it into the public generated positional CBOR/JSON representation and validate every generated argument Type/kind. This module must not choose Message identities, assert an archive ACK, render historical text without schema provenance or bypass native EDP-Memory resource contracts.

Instances are application/record owned and not intrinsically synchronized for concurrent writers; Bootstrap must serialize changes or keep independent records. A false capacity result leaves all previously captured arguments intact, a wrong-Type capture fails rather than coercing, and a returned span cannot outlive its record. No ISR-safety guarantee is made for provider-selected operations or validation. GCC/Clang bounded owner tests and generated strict CBOR/JSON/UTF-8 positives and negatives are retained in [G1–G15 acceptance](../docs/ACCEPTANCE-G1-G15.MD), [owned diagnostics](../docs/DIAGNOSTIC-BOUNDED-ARGUMENTS.MD), [record source assembly](../docs/LOG-RECORD-SOURCE-ASSEMBLY.MD) and [source-side reencoding](Reference-logging-OwnedDiagnosticPositionalReencoding). Native WROOM strict-ACK evidence is only for separately composed complete Logging records, not a stand-alone durability guarantee from this transient arena.

The forward declaration of ESPressio::Clock::ClockEra identifies the existing Clock-owned Type for optional dependent capture. It is an internal owner boundary declaration. It adds no Clock implementation or runtime state. Code instantiating ClockEra capture supplies the owner's complete definition.
