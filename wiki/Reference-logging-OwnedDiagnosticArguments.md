# OwnedDiagnosticArguments — implementation reference

**Classification:** Public opt-in finite source owner. **Owning header:** [src/logging/OwnedDiagnosticArguments.hpp](https://github.com/ESPressio-Development-Platform/EDP-Logging/blob/feature/logging-v1/src/logging/OwnedDiagnosticArguments.hpp). **Version:** 0.1.0, source branch feature/logging-v1. This page describes implementation and owner requirements; it does not replace normative ./docs contracts.

## Responsibility and boundaries

Owns the argument descriptors and fixed inline byte arena for a governed diagnostic record. It copies borrowed argument input before returning, checks exact count/byte capacity, classifies source kinds, and exposes lifetime-limited checked borrowing for downstream generated-schema rehydration.

## Resource, failure and lifecycle invariants

All byte movement delegates to the existing EDP-Memory CopyBytes contract through an application-selectable stateless provider; default is portable. No hidden heap or retained provider pointer. UTF-8 text rejects embedded NUL; use AddBytes only for generated-schema-approved binary data. No descriptor/counter mutation upon refusal.
