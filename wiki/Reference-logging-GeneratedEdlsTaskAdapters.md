# Source reference — generated-record CBOR and typed EDLS Task delivery

**Classification:** PUBLIC OPTIONAL generated-record encoder and synchronous Task-delivery adapter; INTERNAL record/strict ACK/worker Composition seam. **Exact reviewed source:** [src/logging/GeneratedEdlsTaskAdapters.hpp](https://github.com/ESPressio-Development-Platform/EDP-Logging/blob/8d2b307a8a1db1aa5596abc904cd0da1f3c032cd/src/logging/GeneratedEdlsTaskAdapters.hpp). Version 0.1.0. Imports the **existing** EDP-Serialisation typed-envelope canonical CBOR, Logging's typed source/wire projection, EDLS frame and checked archive owner, strict NVS-acknowledged publisher, bounded batch and ordinary coordinator service callback. It creates no duplicate codec, task, queue, thread, timer, filesystem, platform provider or persistent allocator.

## Internal target qualification

`Detail::BatchDeliveryTarget<TTarget>` is an **internal compilation contract** identifying a target that exposes all four exact noexcept operations: `Offer(span<const byte>) -> EdlsBatchOutcome`, `Service() -> EdlsBatchOutcome`, `Flush() -> EdlsBatchOutcome` and `NextFlushDeadline() -> optional<Clock::MonotonicTimestamp>`. **`TTarget`** is the caller's existing bounded EDLS batch type, not a new Logging concrete. This concept selects the **RAM-buffered/worker-service path** at compile time, keeping legacy non-batched immutable archive and strictly ACKed direct publisher semantics separate.

## Public `GeneratedLogRecordCborEncoder<TMessageSchema,TWidth,TMaximumArguments,TArgumentBytes,TParameters...>`

This class adapts the existing `EncodeOnceAndSubmitToSinks` producer to **EDP-Serialisation's canonical TypedEnvelope CBOR**. `TMessageSchema` is the *generated EDP-Localisation message descriptor*, not an ad hoc runtime schema; `TWidth` is the strong per-incarnation attempt ticket width; `TMaximumArguments` and `TArgumentBytes` bound the source-owned argument count/byte arena; `TParameters...` is the exact ordered list of generated owner-certified argument Types. A public typedef-like internal alias **`Source`** selects `BasicLogRecord<TWidth,TMaximumArguments,TArgumentBytes>`; internal **`Projection`** is `GeneratedLogRecordWireProjection<TWidth,TParameters...>`.

Private pointers **`_projection`** and **`_scratch`** borrow Bootstrap-provisioned stable generated projection storage and typed positional scratch. The constructor binds those references without allocating or launching anything. **`operator()(const Source& record,span<byte> output) noexcept`** projects the source against the generated schema and exact strong field identities, measures canonical CBOR `RootProfile::TypedEnvelope`, bounds-checks caller's destination, writes using the existing EDP-Serialisation owner, verifies exact measured/write length and returns typed `RepresentationEncodeResult`: **Succeeded** with measured byte count, **Rejected** for invalid generated record/schema or insufficient caller destination, **ProviderFailure** for inconsistent or failed canonical encoding. No source LogRecord or output span is retained after the call; subsequent sink fanout owns independent copies as required by its own contract.

## Public `TypedEdlsTaskCompletion : uint8_t` — every outcome

- **NotInvoked (0):** no ordinary delivery callback has run in this instance yet; no acceptance proof.
- **Archived (1):** legacy *non-strict* immutable FileStorage archive publication completed under that provider's actual contract; **not** a separate NVS durable ACK.
- **InvalidCodec (2):** source was not supported nonempty bounded canonical CBOR.
- **InvalidTypedRecord (3):** root typed-envelope decode, generated schema/domain/subdomain/message/fingerprint, attempt ticket, strict re-encoding or byte-for-byte canonical representation verification failed.
- **SourceIdentityMismatch (4):** expected application-issued nonzero runtime incarnation or exact 16-byte device identity did not match the decoded complete record.
- **FramingFailure (5):** complete bounded EDLG CRC frame could not be built or batched target rejected an invalid/nonfit frame; no archive acceptance.
- **ArchiveFailure (6):** immutable archive or strict NVS publisher failed, was uncertain, or batch service could not certify completion and needs explicit Bootstrap reconciliation.
- **DurablyAcknowledged (7):** the selected **strict** EDLS FileStorage successor AND independently PowerLoss-atomic KeyValueStorage watermark were both checked/committed; for a batch, this is recorded only when its already owned frames receive a confirmed full-segment completion.
- **BufferedForBatch (8):** a complete checked EDLG frame has been copied into the bounded batch's owned RAM but **has not yet** received any durable segment ACK. A Task terminal status of Accepted at this stage is merely RAM admission.

The nested private `BatchAcknowledgementStatus : uint8_t` has **Confirmed (0)** when `EdlsBatchStatus` was DurablyAcknowledged or DurablyAcknowledgedPendingRetirement and its exact acknowledged-record count was recorded once; **Unconfirmed (1)** for every other observation, causing the callback to report ArchiveFailure instead of manufacturing an ACK. The numeric values are internal and do not allocate wire fields.

## Public `TypedCborProtectedEdlsTaskDelivery<TMessageSchema,TWidth,TPhysicalSlots,TProtectedSlots,TMaximumPayload,TMaximumSegment,TStorage,TParameters...>`

**Template roles:** `TMessageSchema` is generated EDP-Localisation identity/positional argument owner; `TWidth` is the exact attempt ticket width; `TPhysicalSlots` and `TProtectedSlots` are immutable per-archive physical and protected segment capacities with `TPhysicalSlots=TProtectedSlots+1`; `TMaximumPayload` caps encoded canonical CBOR; `TMaximumSegment` caps complete EDLS physical segment bytes; `TStorage` is the *existing, explicitly supplied* abstract FileStorage/strict-ACK `PowerLossAcknowledgedEdls` owner or bounded `BoundedEdlsBatch` target; and `TParameters...` is the exact list of generated argument field Types. A wrong Type/signature fails at compile time where the selected code path is instantiated. No hidden provider selection, runtime schema registry or Heap fallback occurs.

**Every private retained member:** **`Projection`** alias identifies the existing generated structural wire projection for typed input. **`_storage : TStorage*`** borrows the already chosen immutable archive or bounded batch, **`_decoded : Projection*`** borrows the exclusive generated CBOR decode/re-encode projection, **`_framingScratch : span<byte>`** borrows the caller's bounded canonical encoding/CRC frame scratch, **`_archiveScratch : span<byte>`** borrows caller's independent full-segment/archive inspection scratch. The two scratch spans must be valid and sized for their respective tasks and must not alias an in-flight source input. **`_paths : array<FilePathView,TPhysicalSlots>`** captures immutable canonical physical names for the non-strict path; **`_device : array<byte,16>`** captures exact expected source device identity; **`_incarnation : uint32_t`** is expected nonzero application runtime incarnation. **`_pendingDurableCompletions : uint64_t`** is the *authoritative consumable delta* of exact NVS-ACKed **record completions for this sink** not yet reported to its single coordinator service poll; it is neither number of memory-accepted frames nor a global unique source count. No independent counters/queues/timers are created.

The public **`LastCompletion : TypedEdlsTaskCompletion`** is the last ordinary callback/service status (initially NotInvoked), **`LastArchive : EdlsProtectedRollingOutcome<TPhysicalSlots>`** records the legacy non-strict immutable FileStorage publication result, and **`LastAcknowledgement : EdlsAcknowledgedObservation`** preserves the strict-ACK/batch owner observation only when that profile ran. These are observable per-instance state; caller serialization and lifetime are required, and none constitutes a global historic audit ledger.

**Private `ObserveBatchAcknowledgement(outcome)`** checks exactly the strict `EdlsBatchOutcome` acknowledgement status. On a confirmed full-segment ACK (including pending retirement), it adds **`AcknowledgedRecords`**, not segment count, to `_pendingDurableCompletions`, preserves actual native archive observation and sets LastCompletion=DurablyAcknowledged. Otherwise it sets ArchiveFailure/LastAcknowledgement and returns Unconfirmed. No unsuccessful NVS attempt can be treated as a durable completion.

## Public construction, special members and operations

The constructor `TypedCborProtectedEdlsTaskDelivery(storage,decoded,framingScratch,archiveScratch,paths,deviceIdentifier,runtimeIncarnation)` binds existing caller-owned stable objects, checks the protected/physical slot equation at compilation, and does not format media, allocate a Task or emit a log. All references, scratch, paths and provider objects must outlive every submission, worker completion and service poll.

**Conditional copy/move semantics:** for a **non-batching** `TStorage`, copy construction/assignment and move construction/assignment retain the original value-like callback behaviour, subject to the caller maintaining correct borrowed owner lifetimes. For a **batch delivery target**, all four are deleted: a live `_pendingDurableCompletions` delta must not be duplicated or silently transferred to another coordinator and the Bootstrap instance must remain at a stable address. Application code must not bypass this distinction with raw memory copying.

**`ServiceCoordinator() noexcept`**, present **only** when `BatchDeliveryTarget<TStorage>` holds, is invoked in the **same ordinary serialized owner** as input Offer. It calls the existing bounded batch's `Service()`; when the batch actually becomes fully ACKed it records the exact completion delta; Waiting and Empty keep the service Ready, while other non-ACK status sets RecoveryRequired and LastCompletion=ArchiveFailure. It returns `CoordinatorSinkServiceOutcome`: `DurableSinkCompletions` consumes the pending delta **exactly once** (then zeroes it), `NextDeadline` comes from the same batch's canonical monotonic Clock if Ready, and `Status` is RecoveryRequired if an ambiguous archive requires Bootstrap intervention. This call does not spin up a second scheduler or automatically retry an uncertain write.

**`operator()(EdlgCodec codec,span<const byte> encoded) noexcept`** is the main synchronous sink callback behind the actual Threading Task. It rejects non-CBOR, empty or oversized input first, uses EDP-Serialisation to deserialize a complete typed envelope into `_decoded`, validates generated domain/subdomain/string/fingerprint/attempt width and valid attempt ticket, requires exact source incarnation and device identity, **re-measures and re-encodes** the decoded typed envelope with the canonical EDP-Serialisation API into caller-owned scratch, and rejects any different bytes or trailing/alternative encoding before building a CRC-checked EDLG frame.

For **bounded-batch target**, it offers the complete framed representation to existing `TStorage::Offer`. Buffered returns `RecordSinkSubmission::Accepted` and `LastCompletion=BufferedForBatch` **without** claiming durability. If the old batch returns FlushRequired (new input unconsumed), it calls one explicit `Flush` and demands a confirmed strict full-segment ACK before offering the input **once** again; unrecoverable archive state returns ProviderFailure rather than a hidden infinite retry. InvalidFrame/FrameTooLarge returns Rejected; other uncertain state returns ProviderFailure.

For **direct strict archive target** exposing `Publish(...)->EdlsAcknowledgedObservation`, it calls that exact existing strict publisher and reports Accepted / DurablyAcknowledged **only** on AcknowledgedWithinCapacity, AcknowledgedAndRetired or AcknowledgedPendingRetirement (the latter ACK is already proven even though physical retirement needs reconciliation). Any other result remains ArchiveFailure and ProviderFailure. For **legacy non-strict archive target**, it invokes the existing `PublishEdlsProtectedRollingSuccessorWithScratch` and returns Accepted / Archived only on PublishedWithinCapacity or PublishedAndRetired, explicitly without asserting independent NVS acknowledgement. No path duplicates the memory allocator, typed-envelope serializer or FileStorage provider.

## Concurrency, retention and qualification

Bootstrap holds the source identity and canonical generated message contract, allocates decode/scratch/EDLS slots within exact fixed capacities, serializes entire ordinary callback + service with one existing EDP-Threading worker/coordinator, and must not destroy borrowed resources while any Task or outstanding sink completion is live. A failed KeyValueStorage commit leaves source archival truth uncertain and requires explicit recovery; a Task admission Accepted is **not** a durable ACK; a batched worker can retire a source before its record is persisted. Generation retention counts **segments** with bounded frames, not unlimited records. Synchronous callbacks cannot be preempted if a selected provider blocks; ISR and arbitrary target guarantees are not claimed.
