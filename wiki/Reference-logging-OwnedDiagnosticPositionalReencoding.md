# logging/OwnedDiagnosticPositionalReencoding.hpp

**Classification:** optional PUBLIC COMPOSITION API (generated-source to canonical positional serialization), with internal private reconstruction helpers. **No** EDP-Logging umbrella dependency is added.

**OwnedPositionalReencodingStatus** is a compact typed result vocabulary: `Succeeded`, `CountMismatch`, `KindMismatch`, `SourceUnavailable`, `ValueWidthMismatch`, `OwnerValueRejected`, and `EncoderRejected`. None is a wire error tag. `OwnedPositionalReencodingOutcome` stores the high-level status, first failed positional index and unchanged owner `EDP-Serialisation::SerialisationResult`; `IsSuccessful()` demands both successful stages.

**OwnedPositionalScratch<TValues...>** is a caller-owned, compile-time sized tuple of optional exact typed values. Bootstrap must account for its entire finite storage footprint and lifecycle. Both public encoders **clear all scratch entries on success and failure**; no source span survives their return. There is no hidden heap, Thread, captured callback, asynchronous borrowing or platform SDK reference.

**`EncodeOwnedDiagnosticArgumentsCbor<Schema,TValues...>(source,destination,scratch)`** and its JSON counterpart are synchronous optional output operations. Preconditions: the schema must be an actual generated EDP-Localisation declared message, and its kinds/count must match the parameter pack at compile time. The source must be an EDP-Logging private bounded argument arena with the exact same count/position kinds and native widths. Owner values must pass the associated System/Clock/BoundedTypes constructors or assignments. On success each position is reconstructed by value and handed to the existing EDP-Serialisation positional writer; the native arena kind numbers are **never** emitted as CBOR tags. On failure the status and position identify the first source refusal, or the typed owner serialisation result records the encoder refusal; caller output mutation remains subject to EDP-Serialisation's own transactional writer contract.

**Private helpers:** `Detail::LoadOwnedNativeScalar<T>` reconstructs exact native private arithmetic bits using `std::bit_cast`; it has no wire authority. `Detail::LoadOwnedPosition<T>` validates count/descriptors and applies value-specific owner conversions. `Detail::EncodeOwnedImpl<Codec,Schema,TValues...>` checks the generated schema, owns the deterministic positional sequence and clears caller scratch. These are PRIVATE IMPLEMENTATION facilities, not generally substitutable codecs. Supported branches are exact arithmetic (bool 0/1), bounded String/Bytes, System FieldIdentifier, RuntimeIncarnationId, TypeIdentifier and DeviceIdentifier, and optional ClockEra. The returned `EncoderRejected` does not promise end-to-end UART/Persistence durability.

**Tests:** `DiagnosticOwnedStrongGeneratedTests.cpp`, `DiagnosticBoundedGeneratedContractTests.cpp`, `DiagnosticOwnedMixedGeneratedTests.cpp`, executed by their owner generated-schema runners with GCC, Clang and UBSan. Do not infer completed canonical fifteen-field LogRecord root emission, historical decoder, asynchronous sink fork/join or genuine physical PowerLoss from this helper.

## 12 November 2026 — complete source-led declaration, typed results and rehydration

[Exact reviewed C++ header](https://github.com/ESPressio-Development-Platform/EDP-Logging/blob/8d2b307a8a1db1aa5596abc904cd0da1f3c032cd/src/logging/OwnedDiagnosticPositionalReencoding.hpp). This is a **PUBLIC opt-in canonical Field13 encoder** plus explicitly **INTERNAL `Detail` conversion helpers**. It imports the existing source-owned `OwnedDiagnosticArguments` and the exact EDP-Localisation/EDP-Serialisation owner contract. Its native source descriptors and scratch do not become portable CBOR/JSON tags or a second codec.

**`OwnedPositionalReencodingStatus : uint8_t`:** **Succeeded (0)**, every declared source value was reconstructed and the existing encoder accepted it; **CountMismatch (1)**, actual source argument count differs from generated positional template arity; **KindMismatch (2)**, stored private `OwnedArgumentKind` conflicts with the owner-qualified generated C++ `TValue`; **SourceUnavailable (3)**, requested `GetDescriptor`/`GetArgumentBytes` cannot present a complete, still-owned source position; **ValueWidthMismatch (4)**, copied source bytes do not match descriptor size or the exact fixed-width Type; **OwnerValueRejected (5)**, copied bool outside 0/1, invalid issued System identity or invalid bounded String/Bytes reconstruction; **EncoderRejected (6)**, all input positions reconstructed but the canonical EDP-Serialisation encoder declined the requested output. These are typed *source and serialization* statuses, not native durability or UART receipts.

`OwnedPositionalReencodingOutcome` has **`Status : OwnedPositionalReencodingStatus`** (default CountMismatch), **`FirstFailedArgument : size_t`** (zero-based source parameter index for first known refusal, default zero) and **`Encoding : ESPressio::Serialisation::SerialisationResult`** (the native owner result, meaningful after actually attempting output). **`IsSuccessful() const noexcept`** returns true only when high-level Status is Succeeded **and** the native Encoding result confirms success. A source count/kind error must not be reported as valid because output happened to contain old bytes.

**`OwnedPositionalScratch<TValues...>`** is the PUBLIC caller-owned alias `tuple<optional<TValues>...>` with exactly one finite optional slot per generated parameter. Bootstrap provides and budgets this storage. It is explicitly **cleared at entry and on every exit path**, including source mismatch and native encoder rejection, so no constructed strong Type or transient borrowed span leaks between records. Its capacity/size are determined entirely by the exact template C++ Types, never by an unbounded runtime registry.

**Internal `Detail::LoadOwnedNativeScalar<TValue,TByteOperationsProvider>(bytes)`** copies exactly `sizeof(TValue)` into fixed local storage using **EDP-Memory's existing stateless ByteOperations provider** and rehydrates the *source-native* bits via `std::bit_cast`. `TValue` is the exact scalar target, `TByteOperationsProvider` the same provider selected by the enclosing source arena, `bytes` is a borrowed, validated-width span. It is **not** an endianness-portable decoder or a second EDP-Serialisation codec.

**Internal `Detail::LoadOwnedPosition<TValue,N,B,TByteOperationsProvider>(source,index,output)`** takes the bounded arena with exactly N descriptor slots and B byte capacity, a zero-based index, and the caller's one optional typed scratch slot. It requests descriptor and bytes only through the existing arena getters and checks the private kind against `DiagnosticArgumentKindFor<OwnedArgumentKind,TValue>()` before interpreting bits. It enforces exact bool 0/1, primitive-width bit copy, bounded String/Bytes assignments through their owner-contract statuses, strong System FieldIdentifier (one-byte including zero), RuntimeIncarnationId (32 bit), optional ClockEra (owner `FromValue` of exact 64-bit), and TypeIdentifier/DeviceIdentifier fixed-size arrays with validity checks. It returns one of the typed seven statuses and only `emplace`s output on successful owner reconstruction. No runtime heap, memory-copy reinvention, foreign Clock source or type coercion is permitted.

**Internal `Detail::EncodeOwnedImpl<TJson,TGeneratedSchema,TValues...,N,B,TByteOperationsProvider,TIndices...>(source,destination,scratch,index_sequence)`** proves exact generated EDP-Localisation schema/kinds and every canonical EDP-Serialisation `SerialisableType<TValues>` at compile time. `TJson` is **false for CBOR, true for JSON** (not a runtime codec switch); `TIndices...` enumerates every fixed generated positional index in order. It clears scratch on entry, refuses wrong counts before accessing bytes, visits each source position exactly once until first failure while recording that index, delegates the fully reconstructed ordered values to **either** `EncodeDiagnosticArgumentsCbor` **or** `EncodeDiagnosticArgumentsJson`, then clears scratch, and maps a native owner refusal to EncoderRejected without silently retrying or weakening the generated schema.

**Public `EncodeOwnedDiagnosticArgumentsCbor<TGeneratedSchema,TValues...,N,B,TByteOperationsProvider>(source,destination,scratch) noexcept`** is the explicit canonical CBOR Field13 writer; **public `EncodeOwnedDiagnosticArgumentsJson<TGeneratedSchema,TValues...,N,B,TByteOperationsProvider>(source,destination,scratch) noexcept`** is the explicit canonical JSON Field13 writer. `TGeneratedSchema` is the actual generated declared message and source diagnostic fingerprint owner, `TValues...` the exact governing ordered Types, `N,B` the source arena's immutable record argument-count/byte capacities, and `TByteOperationsProvider` the already selected Memory copy owner. Both borrow source, output span and caller scratch only for their synchronous call, select the same typed reconstruction algorithm with a compile-time codec flag, and return `OwnedPositionalReencodingOutcome`. Neither writes a full LogRecord TypedEnvelope, publishes a durable EDLS generation, chooses storage or creates a Task/sink. Its destination bytes' partial-mutation rules remain those of EDP-Serialisation's actual canonical owner; callers must check the complete typed result and never treat a rejected buffer as valid.

This helper's current opt-in Full G3/5 replay and generated-schema/strong owner checks have GCC/Clang/UBSan test receipts. Actual full 15-field record and strict NVS-ACK delivery are owned by later `GeneratedLogRecordWireProjection` and `GeneratedEdlsTaskAdapters` composition and tested separately under the finite WROOM profile; see [owned representation](../docs/OWNED-DIAGNOSTIC-POSITIONAL-REENCODING.MD), [diagnostic schema](Reference-logging-DiagnosticArgumentEncoding), [typed projection](Reference-logging-GeneratedLogRecordWireProjection) and [G1–G15](../docs/ACCEPTANCE-G1-G15.MD). The older text above that described this helper as insufficient evidence for a *then-future* full pipeline is historical, not current release capability.
